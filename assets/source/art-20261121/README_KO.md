# 먼저 가세요 · 아트 통합 전달 2026-11-21

이 ZIP은 지금까지 제작한 원화와 UI 작업을 모은 **게임 연동용 자료**입니다. 실행 가능한 게임 전체 소스나 연동 완료 빌드가 아닙니다. 최신 게임 저장소를 수정하거나 배포하지 않았습니다.

## 포함

- 용도별 PNG 160장: 기본 포즈, 수정 포즈, 추가 연기 12장, 정면/측면/후면 12장, 반송 장면 4장, 5챕터 배경·발판·장식·진입 화면, 엔딩, 타이틀, 초상, 구조 소품·효과, 앱 아이콘 등. 같은 원본의 역할별 복사본과 이전 버전도 있어 160개 완성 기능을 의미하지 않습니다.
- UI SVG 아이콘 24종, CSS 토큰, 정적 화면 예시.
- archive: 미분류 또는 대체된 생성 원본 8장. 기본 연동 대상에서 제외.
- integration-map.json: 권장 캐릭터 상태/챕터 레이어 파일 매핑. 4챕터 구름은 3챕터, 5챕터 구름은 2챕터 파일 재사용.
- ASSET_MANIFEST.json: PNG 원본 이름, 해상도, 알파 정보, SHA-256, 상태. anchor_px의 null은 미실측입니다.
- gallery.html: 더블클릭으로 원화 목록 확인. ui-kit/screens.html은 정적 UI 예시이며 게임이 아닙니다.
- docs: 기존 계획서와 과거 인계서. 과거 문서의 제작 수량은 당시 기준입니다. 현재 목록은 이 README와 manifest를 따릅니다.

## Codex에서 연결하는 순서

1. 최신 게임 저장소의 변경 사항을 보존하고 별도 작업 브랜치에서 시작합니다. 기존 테스트/빌드를 먼저 실행해 기준 상태를 확인합니다.
2. 이 폴더의 assets/를 Vite 프로젝트 public/art/ 안에 복사합니다. 예: public/art/assets/characters/potato/idle_v01.png. ui-kit/icons/는 public/art/ui-kit/icons/로 복사합니다. archive나 docs 전체를 런타임에 복사하지 않습니다.
3. integration-map.json은 개발용 연결표입니다. 각 파일 경로 앞에 `${import.meta.env.BASE_URL}art/`를 붙입니다. 전체 원화를 시작 시 전부 로드하지 말고 현재 캐릭터·챕터에 필요한 파일만 로드합니다.
4. src/art.js의 characterSvg() 호출부를 검토하고 이미지 요소를 사용하는 렌더러로 전환합니다. SVG 문자열 반환을 전제로 하는 호출부를 확인한 뒤 수정합니다. 캐릭터 래퍼의 발바닥 기준점/줄별 깊이 정렬은 유지합니다.
5. 기본 상태는 idle/jump/fall/rescued/finished에 연결합니다. land와 hover는 기존 연출 내부에서 활용하는 단일 포즈입니다. turnaround_*는 외형 참고용, return_parcel은 인물과 상자가 합쳐진 결과 연출용입니다. 반송 원화 위에 캐릭터를 다시 중복 배치하지 않습니다.
6. 챕터 배경은 sky → landmark → back_cloud_* → start/tile/finish → 참가자 → front_*·VFX → 힌트/HUD 순서로 연결합니다. entry는 챕터 진입용 합성 장면이며 플레이 배경 레이어를 대신하지 않습니다. backgrounds/ch02~05의 backdrop은 기존 통합 배경 대안입니다. 레이어 방식과 중복해서 그리지 않습니다.
7. 타이틀·초대장·초상은 ui-kit/art/에 있습니다. 텍스트는 HTML로 표시합니다. UI 예시 전체를 게임 루트에 덮어쓰지 않습니다.
8. 최신 게임 구현이 여전히 1챕터 3스테이지라면 먼저 그 범위에서 검수합니다. 2~5챕터·엔딩 아트가 있다는 이유만으로 새 스테이지나 해금 정책을 자동 추가하지 않습니다.

## 판정과 타이밍 유지

- 이동 420ms, 균열 0~150ms, 공중 유지 150~600ms, 추락 600~1050ms, 구조/반송 1050~1400ms. 이것은 기존 시뮬레이션 시간이며 이미지 파일 자체의 프레임 재생시간이 아닙니다.
- 시각 구조 시작 1050ms와 오디오 rescue 이벤트 1400ms는 다릅니다. 오디오 시점을 임의로 앞당기지 않습니다.
- 판정 전 양쪽 발판은 동일한 정상 tile 이미지를 씁니다. 숨겨진 경로로 그림·색을 바꾸면 안 됩니다. 균열은 공개된 위험 착지 이후에만 표시합니다.
- crack 파일은 균열이 포함된 발판 전체 그림입니다. 투명 균열선만의 오버레이가 아니므로 정상 발판 위 중복 겹침보다 교체 방식으로 우선 검토합니다. collapse는 파편 묶음 한 장이지 분리된 물리 파편/연속 프레임이 아닙니다.
- 제한시간 우선 판정, 위험 착지 후 타이머 정지, finish 1회, NPC 공개 지식 규칙, 진행 저장/해금, 설정과 탭 숨김 시 정지를 유지합니다.
- reduced motion에서는 과장 이동과 회전을 줄이고 기존 판정 시간을 유지합니다. entry를 필수 대기 화면으로 추가해 재시도를 느리게 하지 않습니다.

## 알려진 품질 문제와 미완료

모든 PNG는 원화 시안이며 draft_not_runtime_ready입니다. 투명 채널이 있다고 가장자리가 깨끗하다는 뜻은 아닙니다. 여러 파일에 흰색/노란색/붉은색 잔여 픽셀, 일부에 큰 빛 번짐이 있습니다. 앱 실사용 크기의 경계와 가림 검수를 거쳐야 합니다.

- 발바닥 좌표, 스케일과 시점별 비율은 미실측입니다. alpha_bbox는 불투명 픽셀 범위일 뿐 발바닥 좌표가 아닙니다. 일괄 bottom:center만 적용하면 포즈별 높이가 튈 수 있습니다.
- duck/jump_v01.png는 치아 문제로 제외하고 v02 사용. rabbit/fall_v01.png 대신 여백 수정 v02를 우선 사용합니다. 상자 box_revision_v01은 개선 성공본으로 취급하지 않습니다.
- 반송 감자 대표본은 characters/potato/return_parcel.png입니다. archive의 큰 빛 번짐 버전은 사용하지 않습니다.
- 일부 챕터 도착대 아치/장식과 앞 구름에 외곽 잔여 픽셀/좁은 여백이 있습니다. 4챕터 출발대는 폭/접지 검수가 필요합니다.
- 감자 엔딩의 창밖 다리 표현은 게임의 2열 발판 규칙과 맞추는 수정이 남아 있습니다. 토끼 엔딩의 긴 다리는 의도한 소원 결과이며 기본 캐릭터 비율에 적용하지 않습니다.
- 단일 포즈는 연속 애니메이션 완성을 뜻하지 않습니다. 전용 연속 모션, 눈깜빡임/호흡 분리 파츠, 정렬된 구조 마스크는 추가 작업 대상입니다.
- 실제 BGM·효과음·반응음 파일은 제공되지 않습니다. 기존 Web Audio 임시 합성음을 유지합니다. src/audio.js 교체용 실음원은 이 ZIP에 없습니다.
- 생성 이미지이며 외부 원화·음원 라이선스 증빙을 제공하는 패키지는 아닙니다. 상업 배포 전 적용 서비스 이용 조건과 최종 리소스 검토가 필요합니다.

## 인수 검증

패키지의 모든 PNG 디코드, 연결표 경로, 파일 SHA-256 및 ZIP CRC 검사를 수행합니다. 실제 게임 연동/브라우저 회귀 테스트는 이 전달 작업에서 수행하지 않았습니다.

게임 연결 후 320×568 포함 작은 화면, 캐릭터 발바닥·가림·2열 선택 구분, 연타/동시 착지, 힌트 종료 경계, 추락·시간 종료·즉시 재시도, 설정/탭 숨김/명시적 재개, 저장 복원, 이미지 로딩 실패 대체 표시, 실제 모바일 Safari/Android 메모리·프레임·오디오를 검수하세요. 기존 npm test, npm run test:browser, npm run build도 실행하세요.
