# 먼저 가세요 · 아트 인계 v0.3
2026-11-18 · 원화 시안 묶음. 게임 적용 완료본 아님.

## 구성
PNG 43장: 캐릭터 28장(4명 × 7포즈), 환경 4장, 구조 소품 6장, 콘셉트 2장, 공통 효과 3장.
v0.2의 26장에 오리·토끼 14장과 효과 3장 추가. 감자·비둘기 경로를 assets/characters/{id}/로 통일. PNG 원본 픽셀은 수정하지 않음.

## 표시 및 기준점 제안
캐릭터 래퍼는 기존 80×82 논리 크기, 아래 중앙이 월드 위치다. 충돌/판정에 원화 크기를 사용하지 않는다.
정렬용 공통 논리 캔버스 제안은 128×128, 접지 기준점 (64,112). 이는 원본 PNG의 측정 좌표가 아니다.
대기 자세 발바닥을 기준으로 캐릭터별 배율을 먼저 정하고 모든 포즈에 같은 배율을 적용한다. 포즈마다 전체 bounding box를 같은 크기에 맞추면 몸 크기가 흔들리므로 금지.
토끼 귀와 점프 팔은 래퍼 밖으로 그리되 다음 발판·조작 UI를 가리지 않도록 실제 320px 화면에서 확인한다.
점프/공중/추락의 기준점은 발끝을 쫓지 않고 대기 자세의 몸통 기준에서 유도한 가상 접지점이다. 구조·승리 포즈는 별도 보정 가능.
현재 모든 anchor_px는 null이다. 알파 경계는 번짐을 포함하므로 발바닥 측정값으로 사용하지 않는다.
review.html에서 원본별 투명도·실루엣을 확인할 수 있다. 자동으로 정렬된 스프라이트가 아니다.

## 상태 및 효과 연결 제안
| 상태/이벤트 | 원화 | 시간 |
| --- | --- | --- |
| idle | idle | 정지 표시 |
| jump | jump + takeoff | 이동 420ms, 출발 효과 첫 160ms 제안 |
| land_safe | land + landing | 착지 확정 후 120ms 제안; 입력 잠금 추가 금지 |
| tile_crack | hover | 위험 확정 0–600ms; 기존 0–150ms 균열 유지 |
| fall | fall | 위험 확정 후 600–1050ms |
| 구조 시각 연출 | rescued + rescue | 위험 확정 후 1050–1400ms |
| finish 성공 | finished | 결과 화면 |

각 파일은 단일 포즈이며 연속 모션 프레임이 아니다. 제안 시간은 시각효과만 바꾸며 이동·실패 판정 시간을 변경하지 않는다.
rescue 오디오 이벤트는 현 규약상 1400ms다. 1050ms 시각 시작과 구분한다. 결과 진입의 오디오 정리가 구조음을 즉시 끊는지 확인해야 한다.
레이어: 하늘 → 접수처 → 구름 → 발판 → 효과 뒤쪽 → 참가자 → 효과 앞쪽 → UI. 현재 효과는 앞뒤 분할되지 않았으므로 발/얼굴 가림을 검수한다.
움직임 줄이기: 확대·회전 없이 짧은 정지 효과 또는 생략. 모든 판정 시간 동일.

## 수정 필요
- 구름 효과·발판·일부 캐릭터의 흰색/노란색 외곽 번짐 제거 필요.
- 오리 jump의 치아 표현을 다른 포즈의 부리 디자인과 통일 필요.
- 토끼 fall은 여백이 좁아 회전 시 잘림 점검 필요.
- 구조 상자/구름 전경은 본체와 크기·시점·가림 마스크 정렬 필요.
- 모든 캐릭터 실제 발바닥/몸통 기준점 측정과 공통 배율 확정 미완료.
- 안전/위험 미공개 발판은 동일 원화를 써야 한다. 갈라진 원화는 위험 관찰 공개 후만 표시.

## 검증 범위 및 다음 작업
PNG 디코딩, 파일 수·중복 경로·SHA256, ZIP 무결성만 검증. 게임 코드 연결, 모바일 실기기, 애니메이션, 음원 청음은 미실행.
다음 순서: 외곽 정리 → 기준점 실측/등록 → 320×568 배치 → 이동·추락·재시도·설정·저장 회귀 검증.
음악/효과음 실제 파일, 챕터 2–5, 본편 엔딩, UI 완성본은 이 묶음에 없다.
