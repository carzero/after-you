2026-11-18

계획된 기본 아이콘 24종 SVG 도안 제작. 기존 6종 유지 + 18종 추가. 기본 버튼·보조 버튼·패널·토글·완료 배지의 CSS 스타일 샘플 포함.
review.html은 로컬에서 바로 열리는 검수 페이지다. 실제 게임 기능이 아니며 오디오/저장/이동과 연결되지 않는다. 토글은 표시 상태만 전환한다.

## 규약
viewBox 24×24, 기본 stroke 2.2, 색 #514237. 문구는 HTML. 최소 터치 영역 48×48. 기본·눌림·비활성·포커스 상태 제공.
음악/효과음/진동/움직임 줄이기는 독립 설정 아이콘이다. 켜짐/꺼짐은 토글 문구와 aria-pressed로 함께 전달한다.
안전 체크는 관찰된 안전 발판에만 표시한다. 잠금/해금/챕터 완료는 실제 저장 상태와 연결한다.
독립 파일은 고정색 SVG다. inline 사용 시 stroke를 currentColor로 변경할 수 있다.
도안은 자체 작성 벡터. 외부 아이콘 패키지·폰트·런타임 네트워크 의존성 없음.

## 상태
아이콘 도안 24/24 제작, 실행 화면 통합은 미완료. SVG XML·manifest 경로·ZIP 무결성 검사 수행. 브라우저 캡처는 실행 환경의 소켓 제한으로 수행하지 못함. 실기기 터치·색 대비·게임 회귀 검증은 미실행.
이번 UI 부품은 공통 스타일 샘플이며 전체 선택/결과 화면 제작 완료를 뜻하지 않는다. UI 전체 작업과 P0 원화 외곽·기준점 보정은 계속 필요하다.
