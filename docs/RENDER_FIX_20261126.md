# v0.9.1 · 플레이 중 캐릭터 깜빡임 수정

사용자가 배포한 v0.9의 플레이 중 지속 깜빡임을 보고했습니다. 공개 URL은 환경 네트워크 정책 때문에 직접 검사하지 못했지만, 코드에서 매 RAF마다 actors/board/effects의 innerHTML을 교체해 SVG 이미지가 계속 제거·재생성되는 경로를 확인했습니다.

- keyed DOM 갱신으로 배우·SVG·image 요소를 유지합니다. 표시가 실제로 바뀐 속성/텍스트만 수정하고, 사라진 배우는 제거합니다.
- 기본·등록·착지 직전 포즈의 SVG 구조를 g/image로 통일해 포즈가 바뀌어도 이미지 노드를 재사용합니다.
- 발판과 힌트·효과도 같은 갱신 방식을 사용합니다.
- 구조 화면은 배우 목록과 별도 컨테이너로 유지하고, 구조 중에도 구름과 캐릭터를 매 프레임 다시 삽입하지 않습니다. 1000~1150ms 의도된 구조 가림은 유지합니다.
- 원화 preload는 이미지 decode 완료까지 기다립니다.
- 눈 깜빡임/호흡 모션, 게임 시계·이동 판정·추락 복귀·점수·순위 저장소·Workers migration은 바꾸지 않았습니다.

회귀 검사는 프레임/호흡/눈감기/점프/descent/착지 전환 사이에 실제 동일 DOM sprite 요소가 연결된 상태로 유지되는지 MutationObserver와 node identity로 검사합니다. 기존 게임/사운드/구조/순위 검증도 수행합니다. 실제 배포 기기의 증상 해소 여부는 수정판 재배포 후 확인이 필요합니다.

기존 배포 PC에서 AFTER_YOU_Cloudflare_CMD_v0.9.1.zip을 모두 풀고 UPDATE.cmd를 실행하세요. 기존 Cloudflare 로그인으로 동일 after-you Worker를 갱신합니다. 최초 로그인/인증 갱신이 필요하면 DEPLOY.cmd를 사용합니다. 완료 후 Ctrl+F5로 새 JS를 받아주세요. 신규 계정이나 순위 저장소를 만들거나 기존 데이터를 지우지 않습니다.

검증 결과: 단위·서버 32개, 브라우저 22개, Cloudflare 로컬 두 브라우저 순위 1개 및 단독 HTML 오프라인 시작·이동 검사 통과.
