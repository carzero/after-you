# 스토어 설명 초안

제품 이름: 먼저 가세요 · AFTER YOU

짧은 설명: 길을 기억하고, 먼저 갈 용기를 내세요. 구름 위에서 펼쳐지는 작은 눈치 게임!

설명:
안전한 길을 잠깐 기억한 뒤, 두 발판 중 하나를 골라 앞으로 나아가세요.
친구의 발걸음을 살펴볼 수도, 먼저 달려 아이템을 챙길 수도 있습니다.
떨어져도 구름이 받아줍니다. 한 구간 아래에서 다시 출발해 더 높이 올라가 보세요.

특징:
- 높이 올라갈수록 짧아지는 경로 힌트
- 감자, 비둘기, 오리, 근육 토끼와 함께하는 구름길
- 6번째 안전 발판에 먼저 도착하면 받는 아이템
- 기억 쪽지와 눈치 안경으로 어려운 순간 돌파
- 오프라인 연습과 인터넷 연결 시 온라인 순위 도전

조작: 화면의 왼쪽·오른쪽 버튼 또는 키보드 방향키. 아이템은 보관함에서 선택합니다.

개인정보처리방침 URL: 운영자가 실제 공개 URL 입력
지원 연락처: 운영자가 입력
가격·공개 범위·출시 일정: 운영자가 Partner Center에서 선택
연령 등급: IARC 설문 결과에 따라 입력

인증 담당자 참고:
기본 참가자로 바로 플레이할 수 있습니다. 다른 참가자는 구름 정거장 완료 후 해금됩니다.
별도 계정이나 결제는 필요하지 않습니다. 온라인 기능은 인터넷 연결이 필요합니다.
