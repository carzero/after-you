# v0.9.4 타이틀 밀도 개선

사용자가 승인한 A안 수정 시안을 실제 게임에 반영했습니다. 타이틀 영역을 세로 flex 구성으로 바꾸고, 캐릭터·발판 확대와 머리 가까운 말풍선, ‘양보 중 / 출발자 없음’ 도장, 발판 아래 안내 문구를 적용했습니다.

390×844, 390×740, 320×568, 812×375 화면의 시작 버튼 노출, 가로 넘침, 설정 열기·복귀, 참가자 설정 이동과 실제 게임 시작을 확인했습니다. 기존 플레이와 서버 바인딩은 그대로입니다.

이 환경의 `wrangler whoami` 결과 로그인 정보가 없습니다. Cloudflare에 배포 완료했다고 간주하지 않습니다. 기존 인증된 PC에서 배포 ZIP의 UPDATE.cmd를 실행하면 됩니다.
