# v0.9.3 · 타이틀 A안 적용

승인된 ‘양보하는 척’ 타이틀을 실제 게임에 적용했습니다. 붉은 큰 제목, 감자와 비둘기의 서로 미루는 대사, 발판 원화를 배치했습니다. 기존 단체 포스터와 로고 영역은 타이틀에서 교체했습니다.

시작 버튼은 선택된 참가자와 모드로 게임을 시작합니다. ‘참가자 · 도전 설정’ 링크로 아래의 기존 캐릭터 해금, 스테이지, 닉네임과 온라인 도전 설정에 이동합니다. 시작 버튼과 스코어보드는 하단에 고정됩니다. 타이틀 전용 설정 버튼은 기존 설정 대화상자를 엽니다.

게임 진행, 구조 연출, 해금 조건과 서버 저장 구조는 변경하지 않았습니다. 320×568, 390×844, 1280×900, 812×375 화면에서 시작 버튼, 설정 열기와 복귀, 참가자 설정 이동과 실제 시작을 확인했습니다. 오프라인 HTML 실행과 이동, JavaScript 비활성 안내도 확인했습니다.

GitHub 소스 및 배포 묶음만 갱신하며 이 환경에서 Cloudflare에 직접 배포하지 않았습니다. 배포 묶음의 UPDATE.cmd를 기존 인증된 PC에서 실행하면 서비스에 반영할 수 있습니다.
