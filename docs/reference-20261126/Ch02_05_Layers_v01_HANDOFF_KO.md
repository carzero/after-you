# 2–5챕터 배경·발판 레이어 정리 v01
2026-11-25

## 완료 범위
기존 AFTER_YOU_Art_Integration_20261121에서 개별 레이어·소품·진입 컷신·합성 배경 총 58개 PNG를 그대로 추출했습니다. 새로운 배경 원화 제작 또는 챕터 구현 완료가 아닙니다. 58파일은 SHA256 기준 서로 다른 파일입니다. 시각적 유사성까지 없다는 뜻은 아닙니다.

review.html: 4개 챕터 320×568 배치 비교, 레이어별 표시, 정상/균열/붕괴 발판 전환, 전체 원화 갤러리. 5줄은 검토용입니다. 8/10/12줄이나 이후 챕터 스테이지 수를 변경한 것이 아닙니다. 파일을 모두 압축 해제하고 여세요.

## 레이어 사용
하늘 → 원경 건물 → 후경 구름 → 출발/발판/도착대 → 참가자 → 가장자리 전경 구름 → UI. 참가자 및 UI는 게임에서 연결합니다. 구조 전경 구름은 별도 배우 효과입니다.

entry.png는 진입 컷신, backgrounds/*/backdrop_v001.png는 합성 배경 참고본입니다. 합성 배경 위에 동일 건물·구름을 다시 겹치지 마세요. 소품은 전체 갤러리에 포함했으며 시야 혼잡을 피하기 위해 기본 배치안에는 추가하지 않았습니다.

manifest.json의 displayBounds는 alpha>16 영역이며 표시 여백을 제외하기 위한 값입니다. SVG viewBox로 표시하며 원본 파일은 변경하지 않았습니다. 착지·충돌 좌표가 아닙니다. 정상/균열/붕괴는 각기 다른 외곽 형태이므로 발판 윗면 기준점 등록은 별도 작업입니다.
