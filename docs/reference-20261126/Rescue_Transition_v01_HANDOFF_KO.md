# 구조 전환 v01

정식 전경 구름 후보 원화와 네 캐릭터 추락/구조 원본을 사용하는 독립 검토 화면입니다. 게임 소스 및 이전 승인 PNG는 변경하지 않았습니다. 포함 캐릭터 PNG는 생성 원본이며 최근 알파 보정 패키지를 대체하지 않습니다.

ZIP을 풀고 review.html을 열면 900–1400ms 구간을 재생/정지하거나 슬라이더로 확인할 수 있습니다. 탭 숨김 시 정지하며 명시적으로 재생해야 합니다. 자동 재생·음향은 없습니다.

## 제안 타이밍
- 900–1000ms: 구름 등장, 불투명도 0→1, 30px 상승.
- 1000–1150ms: 캐릭터 렌더링 숨김. 구름 원화의 알파가 최대 254이므로 완전 가림은 별도 visibility 처리로 보장.
- 1050ms: 숨겨진 동안 fall→rescued 교체.
- 1150–1400ms: 구조 자세를 표시하고 구름을 걷음.
- 1400ms: 전환 종료. 기존 게임의 결과·오디오 이벤트 시점은 변경하지 않음.

transition.mjs는 시뮬레이션 시간을 받아 표시값만 반환합니다. 게임 판정이나 이벤트를 생성하지 않습니다. 움직임 줄이기는 구름의 수직 이동만 제거하며 시간·가림 구간은 동일합니다.

## 적용 범위와 한계
캐릭터 캔버스 80px, 구름 240px를 중앙 정렬한 고정 위치 효과 검토입니다. 실제 낙하 궤적과 카메라, 줄 깊이, 옆 참가자 가림, 구조 구름에 앉는 접점은 미연결입니다. 구름은 해당 배우 전용 레이어로 적용하고 다른 참가자 위로 무조건 덮지 마세요. 실제 위치에서 같은 가림 범위가 확보되는지 확인해야 합니다.

네 캐릭터 8포즈의 중앙 정렬 합성에서 본체 영역(alpha>128)은 전부 구름 alpha>=252 영역에 들어갔습니다. 이 수치는 현재 고정 배치에서의 검사이며 모든 게임 위치를 보증하지 않습니다.

검증: 전환 경계 및 전체 900–1400ms 구간의 수치 범위, 숨김 중 자세 교체, 움직임 줄이기 동일 타이밍, JavaScript 구문 검사. 브라우저 실동작·실기기·게임 회귀 검증은 미실행입니다. 본 패키지는 완성 구조 애니메이션이 아닌 적용 후보입니다.
