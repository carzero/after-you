# 4·5챕터 전용 구름 패키지 v03
2026-11-25

## 전용 구름 구성
전용 원화 총 6종: 각 챕터 후경 1종, 왼쪽 전경 1종, 오른쪽 전경 1종. v02에서 갖춘 6종의 투명 가장자리를 정리했습니다. 새 원화를 추가한 작업은 아닙니다. 신규 배치안에서 다른 챕터 구름 재사용을 제거했습니다. before 이미지는 비교를 위해 이전 재사용안을 유지합니다.

## 구성
assets/: 개별 원본 PNG. manifest.json: 원화 해시·크기·표시 범위·배치 좌표. review.html: 교체 전후 정적 이미지 전환. comparison.png: 두 챕터 before/after 4열 비교. 각 ch04/05_after.png는 합성 참고 화면이며 게임 배경을 단일 이미지로 고정하라는 의미가 아닙니다.

## 배치 제약
검토 캔버스 320×568, 5줄 비교용 배치입니다. 실제 스테이지 수·카메라·캐릭터는 미구현입니다. 전경 왼쪽 박스 x=-26,w=65, 오른쪽 x=282,w=70을 사용하여 중앙 발판 영역에서 떨어뜨렸습니다. 화면 컨테이너는 overflow:hidden을 유지하세요. 카메라와 함께 구름을 움직이면 다른 위치에서 가림이 생길 수 있으므로 별도 검사가 필요합니다.

5챕터 왼쪽 PNG는 바깥 윤곽이 이미지 경계에 닿아 있어 왼쪽 화면 가장자리 전용입니다. 현재 배치에서는 잘린 면이 화면 밖으로 나갑니다. 중앙 배치·좌우 이동·폭 축소 시 잘린 면이 드러날 수 있으므로 임의로 재배치하지 마세요. 오른쪽 소재를 별도로 사용하며 조명 방향 때문에 좌우 반전하지 않습니다.

후경 원화 한 장을 두 위치에 재사용합니다. 별도 모양 두 장을 제작한 것이 아닙니다. alpha>16 외곽으로 여백을 제외한 contain 표시이며 표시 배치와 프레이밍은 v02 그대로 유지했습니다. 알파>16의 32픽셀 이상 연결 영역과 외곽 2픽셀을 보존하고 그 밖의 잔재를 제거했습니다. 완전 투명 픽셀의 RGB도 0으로 정리했습니다. 보존 영역 RGBA와 이미지 크기는 원본과 일치합니다.

## 확인
두 챕터 정적 합성에서 중앙 발판 가림과 왼쪽 절단면 노출을 육안 확인했습니다. 6종 원화 해시 및 파일 열기, ZIP 무결성 검사. 실제 브라우저 동작·참가자 가림·UI·실기기·게임 카메라 검증은 미실행입니다.

이 패키지는 v02 구름 배치 후보를 대체합니다. 게임 엔진·기존 사용자 데이터·배포는 변경하지 않았습니다. 아트 제작 후보가 갖춰졌다는 뜻이며 4/5챕터 게임 완성이나 최종 검수 승인을 의미하지 않습니다.

## v03 검사
6종 합계 68,668개의 비영 알파 픽셀을 제거했습니다. 이 수치는 색 번짐 면적을 뜻하지 않습니다. 원본은 original_clouds/에 보관했습니다. edge_review.png는 검정/흰색/민트 축소 비교표입니다. 합성 비교와 축소 가장자리를 육안 확인했으며 픽셀 단위 전수 육안 검사는 아닙니다. 5챕터 왼쪽의 잘린 윤곽은 복원하지 않았고 가장자리 전용 제약을 유지합니다.
