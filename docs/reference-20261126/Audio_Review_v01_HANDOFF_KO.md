# 사운드 기술 점검·청음 패키지 v01
2026-11-25

## 점검 결과
기존 BGM 7곡 + 효과음/반응음 26종 = 33종, WAV/OGG 각각 33개를 재사용했습니다. 음원 수정·신규 작곡·주관적 청음 완료가 아닙니다. 원본 AUDIO_CUES와 AUDIO_MANIFEST를 그대로 보관했습니다.

33 WAV 모두 48kHz/2채널/16bit로 읽혔고, 33 OGG는 ffmpeg 전체 디코딩을 통과했습니다. WAV 최대 샘플 피크는 -3.742dBFS입니다. metrics.json에 RMS, 길이, 끝/시작 샘플 차이와 해시를 기록했습니다. 샘플 경계 차이가 0이어도 리듬이나 잔향 연결이 자연스럽다는 뜻은 아닙니다. OGG의 브라우저 디코딩 길이·지연은 별도 확인해야 합니다.

## 중복 재생 문제
동일 jump를 동시에 시작하고 BGM ch01 시작 부분을 더한 테스트:
- 플레이어 0.65 + NPC 0.2 × 3 + BGM 0.45: 최대 절댓값 0.833737, 범위 초과 샘플 0.
- 효과음 0.65 × 4 + BGM 0.45: 최대 절댓값 1.710925, ±1 초과 채널 샘플 5286.
이는 특정 시작 위치의 수치 시험입니다. 모든 음악 시점·효과 조합을 대표하지 않습니다. 동일 음원을 동시 시작한 극단 사례이며 실제 게임에서 같은 수준의 문제가 관측됐다는 뜻은 아닙니다.

검토 화면에 마스터 0.5를 추가했습니다. 최대 4효과음 + 1BGM만 재생하는 현재 구성의 피크 합산에 여유를 두기 위한 제안입니다. 실제 체감 음량 최종값은 청음으로 정해야 합니다. 원본 WAV를 재정규화하거나 기존 큐 파일을 덮어쓰지 않았습니다. 새 효과·음악 크로스페이드가 추가되면 재검사하세요.

## 청음 화면
ZIP을 전부 풀고 review.html을 엽니다. 개별 음원, BGM 반복, 420ms 안전 착지, 실패 타임라인, NPC 동시음, 4효과음 스트레스 비교를 제공합니다. 마스터 0.5는 항상 적용됩니다. 실패 1400ms에는 finish_fall 우선으로 기존 소리를 정지하고 rescue를 생략합니다. 정지/새 시퀀스/탭 숨김은 재생과 예약 콜백을 모두 취소합니다. 복귀 후 자동 재생하지 않습니다.

HTML Audio 및 setTimeout은 청음용입니다. 게임에서는 시뮬레이션 이벤트와 AudioBuffer 기반 루프를 사용하고, 일시정지·설정·재시도·결과에서 기존 중단 정책을 유지해야 합니다. 반응음은 녹음 음성이 아닌 합성 모티프입니다. 라운드 중복 이벤트 방지는 게임의 drainEvents 정책으로 처리합니다.

## 남은 검증
직접 청음에 의한 음악성/피로도/효과음 구분, 루프 이음새, 브라우저 실제 재생, 모바일 Safari/Android, 실제 게임 중첩·재시도·일시정지 검증은 미실행입니다. 이번 작업은 기술 점검과 청음 도구 제작이며 최종 오디오 승인본이 아닙니다. 게임 코드·배포·사용자 데이터 변경은 없습니다.
