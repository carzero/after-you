## 이번 작업
성공 / 위험 발판 실패 / 시간 종료 / 1챕터 완료 / 참가자 해금의 5가지 결과 화면을 정리했습니다. 기존 캐릭터 원화 12장과 SVG 아이콘 5개를 재사용합니다. 새 캐릭터 원화 제작이나 게임 기능 연결 작업이 아닙니다.

review.html은 320×568 고정 검토 캔버스입니다. 화면 및 캐릭터를 바꿔 문구·원화·버튼을 볼 수 있습니다. 챕터 완료→해금 보기는 시안 내부 이동만 수행합니다. 다른 버튼은 연결 예정 동작을 안내합니다. 저장·오디오·진동·게임 시작은 없습니다.

## 결과 연결 규약
- success는 일반 스테이지 성공. 다음 스테이지와 재도전을 제공합니다.
- 1챕터 마지막 스테이지 성공은 chapter로 분기하며, 미구현 다음 챕터로 이동시키지 않습니다.
- fall과 timeout은 게임이 확정한 원인을 그대로 전달합니다. 위험 착지 이후 시간 종료로 실패 사유를 변경하지 않습니다.
- retry는 기존 게임의 새 Game 생성 흐름에 연결합니다. 결과 화면 자체가 라운드를 복제하지 않습니다.
- unlock은 1챕터 완료에 따른 네 참가자 선택 가능 안내입니다. 재완료 때마다 신규 보상을 반복 지급하는 의미가 아닙니다. 실제 해금/저장 성공 여부는 게임에서 처리합니다.
- 기록의 —는 데이터 미연결 표식입니다. 실제 elapsed/최고 기록으로 대체하며 허위 기록을 만들지 않습니다. 시간 표기 단위와 반올림은 게임 기준으로 맞추세요.
- 화면별 제목·문구·버튼 action은 screen-spec.json을 참조합니다.
