# 1챕터 배경·발판 레이어 v01

기존 전달본의 1챕터 PNG 13종을 재사용해 정리했습니다. 새 원화를 제작한 작업은 아닙니다. 파일 해시를 기록했고 원본은 수정하지 않았습니다.

## 구성과 순서
하늘 → 원경 접수처 → 후경 구름 3종 → 도착대/발판/출발대 → 참가자(게임에서 삽입) → 가장자리 전경 구름 2종 → UI.

entry.png는 진입 컷신용입니다. 하늘 배경과 겹쳐 게임 배경으로 쓰지 않습니다. 구조 전경 구름은 별도 Rescue_Transition_v01 패키지에서 가져오며 배우별 효과 레이어로 다룹니다.

## 검토 화면
압축 해제 후 review.html을 엽니다. 하늘/접수처/후경/발판/전경을 개별로 켜고 끌 수 있습니다. 정상/균열/붕괴 상태를 바꿔 소재를 비교합니다. 전체 발판이 같은 상태로 바뀌는 것은 검토 기능이며 게임 규칙이 아닙니다.

320×568 내부 캔버스에 5줄을 배치했습니다. 실제 스테이지의 8/10/12줄, 카메라 추적, 캐릭터 깊이, 화면 크기에 따른 배치는 Codex가 게임에서 연결해야 합니다. HTML 외부 컨트롤은 검토 도구이므로 모바일 한 화면 게임 UI가 아닙니다.

## 원화 사용
manifest.json의 displayBounds는 알파 >16 기준 표시 영역입니다. SVG viewBox로 여백만 제외해 표시합니다. 외부 16 이하 알파는 표시 범위에서 제외될 수 있으나 PNG 자체는 그대로입니다. 이 좌표를 충돌/발 접점에 쓰지 않습니다. 발판 상태별 형태와 여백이 달라 최종 착지면 등록은 추가 검토가 필요합니다.

하늘은 cover로 표시하므로 기기 비율에 따라 양옆/상하가 잘릴 수 있습니다. 하늘 원화에 이미 일부 구름이 그려져 있어 별도 구름과 겹침을 확인해야 합니다. 가장자리 전경은 중앙 발판을 가리지 않는 위치를 제안했습니다. 실제 캐릭터와 겹침 검증은 아직 하지 않았습니다.

## 확인 범위
13종 PNG 열기 및 파일 해시, 레이어 참조 파일 존재, HTML 스크립트 구문 확인. 원화 전체 비교표 육안 확인. 브라우저 실동작·게임 카메라·캐릭터 가림·모바일 검증 미실행. 게임 코드와 배포는 변경하지 않았습니다.

다음 단계: 게임 화면에 참가자를 얹어 발판 상태별 접점/가림 검토 → 2~5챕터 동일 규약 정리.
