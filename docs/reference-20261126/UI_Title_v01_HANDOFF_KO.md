# UI・타이틀 정리 v01
2026-11-25

## 결과
기존 타이틀 세로 원화(title_portrait.png), 단순화 로고(logo.png), 자체 제작 SVG 아이콘 24종을 한 패키지로 정리했습니다. 신규 원화 제작 또는 전체 UI 제작 완료가 아닙니다. 이번 타이틀 조합은 최종 적용 후보이며 사용자 최종 승인이나 게임 검수 완료를 뜻하지 않습니다.

압축을 풀고 index.html을 여세요. 320×568 타이틀 배치, 버튼 기본/눌림/비활성/키보드 포커스 스타일, 아이콘 갤러리를 확인할 수 있습니다. 시작/설정 버튼은 검토용 안내 대화상자만 엽니다.

## 버전 구분
branding/title_portrait.png: 2026-11-23 제작 패키지의 타이틀 원화.
branding/logo.png: exec-4b4df17d-367b-47f7-a570-1a65124e1dfe의 단순화 로고.
icons/: 기존 UI 아이콘 24종, 수정 없이 유지.
historical/: 이전 화면 흐름, UI 상태 검토, 초상화 및 타이틀/게임플레이 합성 구도 참고. 이전 PNG는 최신 모션 원화 대체용이 아닙니다. 역사적 문서의 제작일과 상태 표기를 유지했습니다.

## 연결 규약
텍스트/버튼은 HTML로 구성합니다. 로고만 문자 포함 브랜드 아트입니다. 48px 터치 영역, 비활성 및 포커스 표현을 유지하세요. 설정 네 항목은 독립 옵션으로 실제 저장 상태와 연결해야 합니다. 안전 아이콘은 관찰된 발판에만 사용합니다.

타이틀 원화는 전체 합성 이미지로 캐릭터·구름·발판이 분리되어 있지 않습니다. 게임 플레이 배경 레이어로 사용하지 마세요. 원화 비율과 기기 비율이 달라 cover 사용 시 여백 일부가 잘릴 수 있습니다. 버튼과 얼굴, 상단 로고의 실제 기기 겹침 확인이 필요합니다. 본 화면은 크기 고정 검토용이며 모든 기기에 대한 반응형 게임 UI 구현이 아닙니다.

## 검사 범위
SVG 24개 XML 파싱, 참조 파일 경로, JavaScript 구문, 파일별 해시 기록. 최신 타이틀/로고 원화 육안 확인. 브라우저 실제 조작, 320px 레이아웃 캡처, 실기기 터치/접근성 대비/게임 회귀 검증은 미실행입니다.
