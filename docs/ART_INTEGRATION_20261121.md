실행용 PNG 역할 124개를 비율 유지 WebP로 변환(약 2,861KiB), UI 아이콘 24개를 연결/보관. `npm run art:prepare`는 원본 전체 해시 확인 후 같은 파일과 `src/art-catalog.js`를 생성한다. 정확한 사용 여부는 ART_USAGE_20261121.json.

- duck jump_v02, rabbit fall_v02를 사용. v01 대체본을 런타임에 넣지 않음.
- 기존 28개 키 포즈 외에 양보/관찰/안도 원화를 공개 발판 정보에 따라 표시. NPC 판단/경로에는 영향을 주지 않음. 포즈별 원본 해상도와 캐릭터별 기존 일정 배율 유지.
- 네 캐릭터의 return_parcel 합성 원화를 실패 결과에 사용. 인물이나 상자를 위에 중복 배치하지 않고 별도 회수 직원만 곁에 둠.
- 5개 배경을 하늘 → 원경/뒤 구름/소품/출발·도착대 → 2열 발판 → 효과 → 캐릭터 → 가장자리 앞 구름 → HUD 순서로 연결.
- 시작 발판은 넓은 월드 평면에 맞춰 환경 레이어로 배치. 네 번째 배경의 큰 정사각 출발대가 경로를 가리지 않도록 표시 높이를 제한. 캐릭터 원화는 늘리지 않음.
- 배경은 5스테이지마다 순환하고, 설정에서 원하는 배경을 직접 선택 가능. 저장 후 재실행 복원. 이는 장식 테마로, 새 스테이지/엔딩/해금 규칙을 추가한 것이 아님.
- 위험 공개 후 0–150ms 균열 발판으로 교체, 150–600ms 파편 묶음을 표시 후 사라짐. 미공개 양쪽은 같은 정상 발판 원화. 공개 전에 경로로 색/그림을 바꾸지 않음.
- 타이틀 배너/초대장/초상/도장/비행 금지/앱 아이콘, 설정/이동/일시정지/재개/재시도/기록/잠금 등의 UI를 제공 소재로 연결. 텍스트/레이아웃/기능은 기존 HTML 유지. 정적 UI 예시 전체를 덮어쓰지 않음.
- 모든 원화를 시작 시 디코드하지 않고 공통 캐릭터/UI와 현재 배경만 로드. 실패한 이미지 요청은 캐시에서 제거해 재시도 가능. 배경 교체 실패 시 기존 배경/설정을 유지하고 플레이 계속 가능. 기본 필수 소재 실패는 출발 전에 재시도 안내.

## 보존한 규칙

Game/progression/server는 변경하지 않았다. 무한 상승, 추락 시 직전 단계, 첫 단계 하한, 짧아지는 힌트, 제한시간 우선 판정, 최고 안전 도달 층수, 서버 검증/중복 등록 방지, 기존 캐릭터 해금은 동일.

이동 420ms, 균열/공중/추락/구조 0–150/150–600/600–1050/1050–1400ms. rescue 오디오 1400ms와 시각 구조 1050ms를 구분. 사운드는 기존 임시 Web Audio를 유지한다.

일시정지/설정/백그라운드/배경 로딩 동안 시뮬레이션과 포즈·효과가 함께 멈춘다. 설정을 닫을 때 입력 상태를 즉시 갱신. 재시도 시 착지·도약·균열 기록 초기화. 움직임 줄이기는 기존 판정 시각을 유지한다.

## 아직 플레이에 넣지 않은 소재

챕터 진입 합성컷/대체 backdrop, 4개 본편 엔딩, 외형 참고용 turnaround, 콘셉트, archive, 대체된 초기 원화는 원본으로 보존한다. 무한 모드에 임의의 엔딩·강제 대기·해금 조건을 추가하지 않았다. UI 키트의 사용하지 않는 아이콘도 향후 작업을 위해 보관.

모든 PNG는 여전히 초안이다. 외곽 잔여 픽셀/빛 번짐/독립 포즈 비율 차이는 남아 있다. 연속 모션·추가 파츠·실제 음원·최종 상업용 리소스 검토와 실기기 검수는 별도다.
