# 아트 v0.3 적용 기록 · 게임 v0.5

2026-11-18 · 제공 패키지의 PNG 43개 해시를 확인했고 원본은 `assets/source/art-v03/`에 보존했다. 원본 manifest의 미측정 anchor/null 및 초안 상태는 변경하지 않았다. v0.2의 기존 26장은 픽셀이 동일하고 캐릭터 경로가 characters/{id}로 통일됐다.

## 연결과 배율

- 주연 4인 × 7포즈(idle/jump/land/hover/fall/rescued/finished) 전부 사용. 기존 오리·토끼 임시 SVG를 교체했다.
- `src/art-layout.js`에 수동 기준점과 캐릭터별 고정 배율을 등록. 정확한 좌표는 `ART_REGISTRATION.json` 참조. 알파 경계로 기준점을 자동 추정하지 않는다.
- 공통 렌더 캔버스 128×154, 접지 위치 (64,154). 이는 제공 문서의 제안 (128×128,64×112)을 자동 적용한 것이 아니라 기존 게임의 월드 래퍼에 맞춘 실제 적용값이다.
- 감자/비둘기는 기존 크기를 보존(128/1254 배율). 오리 .099, 토끼 .104 배율은 포즈 전체에 고정. 점프/hover/fall은 대기 몸통에서 유도한 가상 접지점으로 배치한다.
- 오리 land의 원본만 1312×1199이고 다른 포즈는 1178×1335이므로 각각 실제 가로세로 비율로 렌더한다. 토끼는 1199×1312. 이미지를 정사각형으로 늘리지 않는다.
- 토끼 귀/팔은 SVG 래퍼 밖 표시를 허용. 화면 바깥으로 내려가는 추락은 장면 뷰포트에서 가리되 스프라이트 자체의 여백 때문에 잘리지 않도록 한다.

## VFX

- takeoff: jump 승인 후 160ms, landing: land_safe 후 120ms. 참가자 뒤 레이어에 배치해 얼굴을 가리지 않는다. 추가 입력 잠금 없음.
- rescue 시각 효과: 위험 확정 후 1050–1400ms, 쿠션·구조 포즈 뒤에 배치. 오디오 rescue 이벤트는 기존 1400ms로 유지.
- 일시정지 시 효과 나이/투명도도 정지. 재시도 시 도약/착지 기록을 지워 이전 효과가 남지 않음. 감소 효과 설정/OS 동작 줄이기에서는 세 효과를 생략.
- 기존 균열 발판 공개는 위험 착지 이후에만, 기존 시간과 판정 정책 유지. 비공개 안전·위험 발판은 같은 정상 원화 사용.

## 파일

`npm run art:prepare`: 원본 43개 해시 확인 후 비율 유지 WebP 생성. 실행용은 `assets/runtime/art-v03/`의 40개(캐릭터28/환경4/회수5/VFX3). 콘셉트2장과 box_revision은 보존만 한다. 원본 번짐을 지우거나 디자인을 다시 생성하지 않았다.

원본 ZIP은 용량 때문에 3개로 나눠 GitHub downloads에 제공. 같은 상위 폴더에 풀면 소스 ZIP의 `assets/source/art-v03/assets/`와 합쳐진다. 새 소스 ZIP만으로 실행·수정·빌드 가능하며, 원본 재가공 때만 추가 ZIP이 필요하다.

## 남은 품질 항목

외곽의 흰/노란 번짐과 토끼 fall 주변 잡픽셀은 그대로다. 오리 jump의 치아는 다른 부리 포즈와 디자인 통일이 필요하다. 독립 생성 포즈의 체형/시점 통일, 연속 프레임, 실제 음원, 실기기 검수와 최종 라이선스 확인은 미완료. 이번 작업은 전달된 초안을 연결·정렬한 것이며 최종 원화 완성으로 표시하지 않는다.

## 기준점과 크기

감자 idle 1장부터 320×568 화면에서 확인 후 나머지 포즈를 연결했다. `src/art-layout.js`의 수동 등록값은 **원본 1254×1254 좌표계**다. alpha_bbox를 발바닥으로 사용하지 않는다.

| 포즈 | 감자 발 기준점 x,y | 비둘기 발 기준점 x,y |
| --- | --- | --- |
| idle | 675,1194 | 625,1194 |
| jump | 640,1120 | 640,1105 |
| land | 690,1100 | 630,1120 |
| hover | 635,1200 | 635,1190 |
| fall | 650,1205 | 650,1205 |
| rescued | 665,1195 | 640,1200 |
| finished | 670,1190 | 635,1195 |

각 기준점을 렌더 SVG의 `(627,1505)` 아래 중앙에 배치. 원본 캔버스 비율을 그대로 두고 포즈별 위치만 등록한다. 전경 실루엣과 바닥의 육안 접촉점을 사용한 초안 등록이며, 비접지 포즈는 논리적 발 기준점이다. idle/jump/land 사이 자세 변화는 독립 키 포즈이며 연속 프레임 보간이 아니다. 원본 저알파 가장자리와 캔버스 아래 잡픽셀 일부는 SVG 뷰포트 밖으로 나갈 수 있다.

플레이어 72px, NPC 55px(320px 화면에서는 64/48px) 래퍼에 맞춘다. 로비·선택·결과도 같은 등록값을 사용한다. 정상 착지 포즈는 160ms 표시하지만 다음 입력을 막지 않는다.

## 시각 타이밍과 레이어

- jump: 420ms 전체 키 포즈. 위치는 기존 시뮬레이션 이동 보간.
- 위험 착지 0–150ms: land + 균열 발판; 150–600ms hover; 600–1050ms fall; 1050–1400ms rescued + 구름 회수 연출.
- 결과: 성공 finished, 추락 rescued + 상자/회수 직원, 시간 종료 idle.
- 레이어: 하늘 → 접수처 → 발판 → 배우 → 회수 쿠션 본체 → 구조 포즈 → 쿠션 앞면/직원 → HUD/결과.
- 쿠션 앞면은 본체 폭의 86%, 좌측 7%, 바닥 9px(장면에서는 7px)에 수동 정렬. 상자 앞면은 본체와 같은 폭/좌표에 별도 정렬. 앞면만 교체 시 이 값을 재검토.
- 일시정지 시 시뮬레이션 시간이 정지해 포즈도 유지. 움직임 줄이기는 수직 과장/회전을 제거하고 판정·포즈 시점을 유지.
- 출발 전 모든 실행용 이미지를 로드. 실패하면 출발을 진행하지 않고 재시도 안내. 라운드 초기화 시 착지 시각/회수 레이어도 초기화.

## 검증과 남은 품질 작업

320px/375px 화면, 키 포즈 전환·일시정지·회수 앞면 가림·결과·재시도, 3스테이지 클리어·해금·저장 복원 회귀 확인. 원본의 외곽 빛 번짐은 남아 있으며 특히 발판/상자/쿠션은 초안 품질이다. 원본별 독립 생성에 따른 시점·체형 차이는 최종 원화에서 통일 필요. 실기기 검수·라이선스 최종 확인·연속 모션 프레임은 별도 미완료.
