# 대기 모션 검토 작업 v0.2 · 2026-11-24

업로드된 AFTER_YOU_Idle_Review_v01.zip을 기반으로 만든 별도 검토 도구입니다. 실제 게임과 기존 배포 파일은 바꾸지 않았습니다.

## 완료한 작업

- 원본 PNG 12장의 SHA256, 해상도와 전체 디코딩 검사 통과. 원본 이미지를 변형 없이 단일 HTML에 포함했습니다.
- 시각 확인으로 발 기준점 초안을 잡았습니다. 알파 외곽 상자를 발 위치로 사용하지 않았습니다. 수동으로 조절하고 JSON으로 내보낼 수 있습니다.
- 캐릭터별 다른 간격/위상의 100ms 깜빡임. 일시정지와 탭 숨김 중에는 검토용 시계가 멈추며 복귀 시 시간을 건너뛰지 않습니다.
- 기본 이미지를 발 기준으로 최대 0.8% 늘리는 2.8초 호흡 비교안. 들숨 원화로 전신을 전환하거나 크로스페이드하지 않습니다. 부위별 호흡을 대체하는 완성 애니메이션은 아닙니다.
- 운영체제와 화면의 움직임 줄이기 설정 지원. 이동·추락·구조 상태 선택 시 대기 모션을 중지합니다. 이 선택기는 게임 동작 자체를 재현하지 않습니다.
- 80px/확대 및 검정/흰색/민트 배경 비교. 인터넷과 서버 없이 실행됩니다. 파일 미리보기 대신 실제 브라우저에서 여세요.

## 시각 확인과 남은 작업

- 기본 대기와 닫힌 눈 사이에서 감자 눈의 돌출감이 달라집니다.
- 들숨 후보는 호흡 외에도 넥타이·옷깃·깃털·몸 실루엣이 달라집니다. 중간 프레임 없이 번갈아 재생하는 게임 적용은 보류했습니다.
- 발 기준점은 손으로 잡은 검토 초안입니다. 포즈별 추가 조정과 게임 크기에서의 승인이 필요합니다.
- 알파 경계와 토끼의 흰 영역은 정리하지 않았습니다. 밝은 털과 잔여 배경의 구분은 원화 수정이 필요합니다.
- 눈과 얼굴을 다시 그리는 작업, 신규 중간 프레임 제작 및 게임 통합은 하지 않았습니다.

## 실행과 검증

`downloads/AFTER_YOU_Idle_Review_v02.html`을 실제 브라우저에서 여세요. 수동 포즈를 고르고 발 X/Y를 편집하거나 발 사이를 클릭한 뒤 `기준점 JSON 저장`으로 조정값을 보관하세요. JSON 불러오기 기능은 아직 없습니다.

원본 ZIP을 압축 해제한 다음 저장소 루트에서 재생성:

```
node tools/idle-review/build.mjs /path/to/AFTER_YOU_Idle_Review_v01
node --test tools/idle-review/motion.test.mjs
node tools/idle-review/browser-check.mjs
```

모션 단위 검증 3개 통과. 관리형 Chromium에서 서버 없는 opaque origin/오프라인 실행, PNG 로딩, 포즈 전환, 기준점 편집·다운로드, 일시정지, 움직임 줄이기, 상태 우선순위, 390px 모바일 레이아웃 검증 통과. 실제 휴대폰이나 file:// 탐색 검증은 하지 않았습니다.
