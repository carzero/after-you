# v0.9.5 플레이어 문구 정리

플레이 화면의 ‘배경·모션·사운드 통합 초안’과 숨겨진 타이틀의 원화·음원 적용 안내를 제거했습니다. 설정의 제작 완료 문구도 제거했습니다.

접속 안내의 서버 용어를 온라인 도전으로, 결과·재시도 버튼의 STAGE 표기를 구간으로 바꿨습니다. 저장 오류와 순위 이용 불가 안내는 플레이어가 다음에 할 수 있는 행동을 알려주도록 정리했습니다. 시작 및 기록 확인 실패 시 내부 오류 메시지·서버 오류 응답을 그대로 표시하지 않습니다.

세계관과 타이틀의 의도된 영문 장식, 조작 안내, 해금 조건은 유지했습니다. Cloudflare 배포는 별도이며 이 환경에는 인증이 없습니다.
