# 게임 v0.5 · 아트 v0.3 적용

온라인 API/진행/순위 규칙은 아래 v0.4와 동일하다. 최신 배포 ZIP은 AFTER_YOU_Server_v0.5이며 같은 명령으로 실행한다.

# 끝없이 올라가기 + 온라인 스코어보드 v0.4

## 진행 규칙

- 성공: 다음 스테이지. 3스테이지 이후에도 같은 구름 정거장 아트로 계속 생성.
- 추락: 정확히 한 스테이지 아래에서 새 경로로 다시 출발. 첫 스테이지에서는 첫 스테이지 유지. 구조/반송 후 버튼 한 번으로 계속 도전하며 생명 소진이나 게임 오버 없음.
- 시간 종료: 현재 스테이지에서 다시 출발.
- 힌트: 1스테이지 2.6초, 이후 스테이지마다 0.2초 감소, 최소 0.6초. 행 수는 8줄부터 2줄씩 늘어 최대 20줄, 제한시간은 35초부터 최대 50초.
- 점수: 지금까지 도달한 가장 높은 **안전한 층수**. 스테이지 경계를 이어 센다(1스테이지 8층, 2스테이지 누적 18층, 3스테이지 누적 30층). 추락한 위험 발판은 세지 않음. 내려갔다가 이미 오른 구간을 반복해도 중복 점수가 쌓이지 않음.
- 온라인은 반드시 STAGE 1부터 새 도전. 연습의 스테이지 선택/브라우저 최고 기록은 온라인 순위와 분리.

## 배포 ZIP을 받은 경우

압축을 푼 `AFTER_YOU_Server_v0.4` 폴더에서 Node.js 24로 실행:

```sh
DATA_DIR=/absolute/persistent/path PORT=8787 npm start
```

ZIP은 이미 빌드된 게임을 포함한다. 설치나 다시 빌드할 필요가 없다. 아래 build/serve 명령은 소스 저장소 개발용이다.

## 서버 실행

Node.js 24. 설치된 저장소에서:

```sh
npm run build
DATA_DIR=/absolute/persistent/path PORT=8787 npm run serve
```

서버는 정적 게임과 `/api/*`를 함께 제공한다. 같은 서버 주소에 접속한 사람들이 하나의 순위표를 공유한다. 개발할 때는 별도 터미널의 `npm run dev`가 8787번 API에 프록시한다.

실행만 하는 배포 묶음은 `dist/`, `server/`, `src/game.js`, `src/progression.js`, `package.json`으로 구성하며 외부 런타임 npm 패키지 없이 `node server/index.mjs`로 시작할 수 있다. 파일 저장이 가능한 **단일 Node 인스턴스**를 사용하고 DATA_DIR을 영구 디스크에 연결한다. 정적 파일 호스팅만으로는 온라인 기록이 공유되지 않는다. 정식 주소에는 호스팅의 HTTPS를 연결한다.

현재 Cloud 내부 서버/독립 브라우저 검증은 완료했으나 **외부 공개 배포는 하지 않았다.** 도메인/호스팅이 정해져야 다른 기기에서 실제로 접속할 주소를 제공할 수 있다. 다운로드 HTML은 인터넷 없이 하는 연습판이며 온라인 서버 연결 없음으로 표시한다.

## 점수 등록과 복구

- `POST /api/runs`는 닉네임(1~16자)과 새 도전을 등록하고 서버의 난수 시드/스테이지 토큰을 발급.
- 클라이언트는 각 라운드의 승인된 이동 입력/시뮬레이션 시각만 기록.
- `POST /api/runs/:id/checkpoint`에서 서버가 같은 경로를 재생해 입력 간격/제한시간/도달 층수/추락·진행을 계산. 클라이언트의 score/진행 숫자는 사용하지 않음.
- 서버 시간보다 빠른 기록, 잘못된 토큰/중복 입력/과대 요청/다른 출처의 POST를 거부. 도전 시작은 IP당 시간당 60회로 제한.
- 응답만 유실된 체크포인트 재전송은 동일한 결과를 돌려줘 중복 점수를 만들지 않음. 네트워크 실패 시 다음 출발을 잠그고 재전송 버튼 표시. 홈으로 돌아가 연습으로 전환 가능.
- `GET /api/leaderboard`: 최고 층수 내림차순 TOP 20. 동점은 먼저 기록한 도전 우선. 최대 1,000개의 도전 기록을 서버에 보관.
- 파일은 임시 파일 쓰기 후 이름 교체로 저장. 서버 재시작 뒤 순위는 복원. 진행 중 토큰은 메모리에 있어 재시작/1시간 미사용 시 새 도전을 시작해야 함. 잘못된 기존 데이터 파일을 자동으로 덮어쓰지 않음.

## 현재 온라인판의 범위

닉네임 기반 익명 도전이며 계정/친구 목록/닉네임 소유권은 없다. 같은 닉네임이 여러 번 표시될 수 있다. 봇이나 힌트 자동 해석을 막는 완전한 부정행위 방지 시스템은 아니다. 상금/유료 대회용 인증 순위로 사용하기 전 계정·운영 정책·추가 서버 검증이 필요하다. 현재는 프로토타입 기록 경쟁을 위한 서버 검증이다.

닉네임은 순위표에 공개된다. 이메일/비밀번호는 수집하지 않으며 IP 제한은 메모리에서만 사용한다. 순위 서버 장애/손상 파일/디스크 권한 실패는 실제 오류로 안내하고 연습 기록을 온라인 기록처럼 표시하지 않는다.
