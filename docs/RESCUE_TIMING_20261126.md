# v0.9.2 · 추락과 구름 구조 장면을 충분히 보여주기

사용자가 추락 뒤 구름이 받아주는 장면을 알아보기 전에 결과 화면으로 넘어간다고 보고했습니다. 기존 구조 자세는 약 250ms만 보였습니다.

## 변경

- 플레이어가 실패했을 때, 실패 시계의 600ms 이후는 화면에서 절반 속도로 진행합니다. 추락 포즈 구간 450ms가 실제 화면에서 약 900ms로 늘어납니다. 앞의 균열/공중 망설임은 늘리지 않습니다.
- 게임은 기존 1400ms에서 실패를 확정하지만, 결과 패널은 구름 안착 화면을 1600ms 추가 유지한 후 표시합니다. 구조 자세는 기존 노출 구간까지 합쳐 약 2.1초 보입니다.
- 구름 위 캐릭터와 `구름이 받아줬어요!` 안내를 함께 보여줍니다. 구름 받침/안내의 위치가 바뀌지 않게 안내는 독립 절대 배치합니다.
- 구조 휴식 중 일시정지·설정·탭 숨김은 표시용 시계도 멈춥니다. 두 번째 추락부터 기존 건너뛰기로 느린 추락 또는 추가 휴식을 생략할 수 있습니다.
- score/replay Game, FALL_MS=1400, 안전 발판 판정, 점수, 스테이지 복귀와 순위 저장소는 바꾸지 않습니다. 온라인 제출 end는 실제 Game.clock이며 화면 대기 시간을 보태지 않습니다. 서버의 동일 이동 기록 재검증을 그대로 사용합니다.
- 성공·시간 종료·명시적 구조 건너뛰기에는 추가 대기를 넣지 않습니다. 기존 깜빡임 수정과 대기/착지 모션을 유지합니다.

## 구현과 검증

`src/rescue-presentation.js`가 표시용 감속/휴식을 담당합니다. 실제 실패 판정과 이벤트는 `src/game.js`가 담당합니다. 대기는 setTimeout 대신 일시정지 가능한 프레임 시계로 처리합니다. 구름 받침 소리는 휴식 시작에 한 번, 결과음과 온라인 제출은 결과 화면을 표시할 때 한 번 처리합니다.

순수 검사로 2200ms의 실제 추락 연출 뒤에도 게임의 실패 end 차이가 1400ms인지 검증합니다. 브라우저 검사로 추락 포즈 유지·구름 안착·안내·지연된 결과 표시·휴식 일시정지·재시도·구조 건너뛰기를 확인합니다. 실제 배포 기기의 체감은 재배포 후 확인이 필요합니다.

배포 방식은 동일합니다. GitHub 자동 배포가 연결된 경우 이 브랜치 변경을 배포합니다. CMD 방식이면 AFTER_YOU_Cloudflare_CMD_v0.9.2.zip의 UPDATE.cmd를 기존 배포 PC에서 실행하고 새로고침하세요. Worker/영구 저장소 이름 및 migration은 유지합니다.

최종 검증: 단위·서버 35개, 브라우저 23개, Cloudflare 로컬 두 브라우저 순위 1개 및 오프라인 시작·이동 통과. 화면 캡처로 구름 위 캐릭터와 안내 배치를 확인했습니다. 원격 공개 사이트 배포 상태는 이 환경에서 확인하지 못했습니다.
