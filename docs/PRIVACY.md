카제로 Carzero는 「먼저 가세요」 웹 게임과 Windows 앱에서 아래와 같이 정보를 처리합니다. 이 방침은 게임 운영자가 처리하는 정보에 관한 안내이며, Microsoft Store·Windows·WebView2 및 Cloudflare가 자체 서비스 제공 과정에서 처리하는 정보에는 각 제공자의 방침도 적용됩니다.

## 1. 어떤 정보를 처리하나요?

### 기기 안에 저장하는 정보

게임은 브라우저 또는 Windows 앱의 사용자별 저장 공간에 해금한 참가자와 구간, 최고 도달 높이, 구간별 최고 기록, 배경 및 소리·진동·움직임 설정을 저장합니다. 이 저장 정보 전체를 운영자에게 자동 업로드하거나 다른 기기와 자동 동기화하지 않습니다. 웹 브라우저와 Windows 앱의 저장 공간은 서로 다릅니다.

아이템 보유 상태는 한 번의 도전 동안 유지됩니다. 온라인 도전에서는 서버가 보유 상태를 검증·관리하며, 새 도전이나 앱·페이지 재시작으로 초기화됩니다.

### 온라인 도전 및 순위 정보

온라인 도전을 이용하면 다음 정보를 게임 서버로 전송·처리합니다.

- 입력한 닉네임 (입력하지 않으면 화면에 표시된 기본 닉네임)
- 도전 식별자, 도전·구간 진행 정보, 최고 도달 높이 및 기록 갱신 시각
- 이동 입력 시각, 선택한 발판, 아이템 사용 입력 등 기록 검증에 필요한 플레이 정보
- 서버가 생성한 도전 확인용 값과 아이템 보유·보상 상태

서버는 플레이 입력을 재현해 순위 기록의 유효성을 확인합니다. 원본 이동·아이템 입력 목록을 게임 데이터베이스에 별도 장기 보관하지는 않습니다. 검증 후에는 도전 상태와 결과, 순위 정보를 저장합니다. 닉네임에 실명·전화번호·이메일 등 개인정보를 넣지 마세요.

### 접속 및 운영 정보

온라인 기능 확인과 게임 이용 과정에서 IP 주소 등 접속 정보가 서버 제공자에게 전달될 수 있습니다. 앱은 실행 시 온라인 이용 가능 여부를 확인할 수 있으므로, 연습 모드를 선택하더라도 인터넷에 연결된 상태에서는 접속 확인 요청이 발생할 수 있습니다.

게임의 Cloudflare 서버는 반복 요청 제한을 위해 IP 주소에서 생성한 SHA-256 해시값, 요청 횟수와 제한 기간의 시작 시각을 게임 데이터베이스에 저장합니다. 게임 데이터베이스의 요청 제한 표에는 원본 IP 주소를 저장하지 않습니다. 해시값을 사용한다고 해서 모든 접속 정보가 완전히 익명화된다는 뜻은 아닙니다. Cloudflare는 서비스 제공과 보안을 위해 원본 접속 정보와 운영 로그를 별도로 처리할 수 있습니다.

### 문의 정보

이메일로 문의하거나 개인정보 관련 요청을 하면 이메일 주소와 문의 내용, 요청 처리에 필요한 확인 정보를 문의 응대 목적으로 처리합니다. 문의와 관계없는 민감한 정보는 보내지 마세요.

## 2. 어떤 목적으로 사용하나요?

- 게임 진행 상황과 개인 설정 유지
- 온라인 도전 진행, 아이템 상태 확인 및 순위 제공
- 비정상 기록·과도한 요청 방지, 오류 대응 및 서비스 안정성 유지
- 이용자 문의와 개인정보 열람·정정·삭제 요청 처리

현재 게임 자체에는 광고 또는 이용자 행동 분석 SDK, 회원가입, 유료 결제 기능이 없습니다. 게임은 실명, 연락처 목록, 사진, 마이크, 카메라 또는 정확한 위치를 요구하지 않습니다.

## 3. 다른 사람에게 공개되나요?

온라인 순위표에는 **닉네임, 최고 도달 높이, 기록 갱신 시각**이 표시될 수 있습니다. 현재 공개 순위 조회는 상위 20개 기록을 제공합니다. 온라인 도전 식별자나 확인용 값, IP 해시값을 공개 순위표에 표시하지 않습니다.

운영자는 정보를 광고 목적으로 판매하지 않습니다. 서비스 제공에 필요한 인프라 이용과 법령에 따른 처리를 제외하고 이용자 정보를 임의로 공개하거나 제공하지 않습니다.

## 4. 어디에서 처리하나요?

웹 게임 파일과 온라인 도전·순위 기능은 **Cloudflare Workers 및 Durable Objects**를 사용합니다. Cloudflare의 글로벌 인프라 특성상 정보가 대한민국 외 지역에서 처리될 수 있습니다. 실제 처리 지역과 인프라 로그 보관은 Cloudflare의 서비스 구성 및 정책에 따릅니다.

Windows 앱은 **Microsoft Edge WebView2**를 이용해 기기에 포함된 게임을 표시합니다. Microsoft Store, Windows, WebView2 자체의 계정·구매·진단·보안 정보 처리는 Microsoft의 해당 서비스 방침을 확인해 주세요. 게임 운영자는 Microsoft 계정의 비밀번호나 결제 수단 정보를 받지 않습니다.

- [Cloudflare 개인정보처리방침](https://www.cloudflare.com/privacypolicy/)
- [Microsoft 개인정보처리방침](https://privacy.microsoft.com/privacystatement)

## 5. 얼마나 보관하나요?

- **기기 내 진행·설정:** 해당 브라우저 또는 앱의 사용자 데이터를 삭제할 때까지 유지될 수 있습니다. 앱 제거만으로 모든 사용자 프로필이 삭제된다고 보장하지는 않습니다.
- **온라인 도전 상태:** 마지막 활동 후 1시간을 기준으로 만료됩니다. 만료된 데이터는 이후 도전 관련 서버 요청을 처리할 때 정리하므로 실제 삭제 시점은 요청 발생 시점에 따라 달라질 수 있습니다.
- **요청 제한용 IP 해시·횟수:** 제한 기간 시작 후 1시간을 기준으로 정리 대상으로 삼으며, 이후 도전 관련 요청 처리 시 정리합니다.
- **온라인 순위:** 현재 상위 1,000개 기록을 보관합니다. 순위 범위를 벗어나 정리되거나, 확인 가능한 삭제 요청이 처리되거나, 서비스 종료 시 정리될 때까지 남아 있을 수 있습니다. 일정 기간이 지나면 모든 순위가 자동 삭제되는 구조는 아닙니다.
- **문의 내용:** 문의와 요청 처리 및 필요한 후속 대응을 위해 보관하며, 더 이상 필요하지 않은 정보는 삭제합니다. 법령에 따라 보관이 필요한 경우에는 해당 기간을 따릅니다.

인프라 제공자의 접속·운영 로그나 백업에는 게임 데이터베이스와 다른 보관 정책이 적용될 수 있습니다.

## 6. 저장·공개를 원하지 않으면 어떻게 하나요?

온라인 순위 참여를 원하지 않으면 출발 전 **온라인 순위 도전**을 해제하고 연습 모드를 이용하세요. 연습 기록은 공개 순위에 등록하지 않습니다. 단, 웹 접속이나 온라인 이용 가능 여부 확인에 필요한 접속 요청은 별개입니다.

기기 내 진행 정보는 브라우저의 해당 사이트 데이터 또는 앱의 사용자 프로필 데이터를 삭제하여 지울 수 있습니다. 삭제하면 해금·최고 기록·설정도 복구되지 않을 수 있습니다.

온라인 기록의 열람·정정·삭제를 원하면 **kaelsiem@naver.com**으로 연락해 주세요. 요청한 기록을 찾기 위해 닉네임, 도달 높이, 대략적인 기록 시각 등 필요한 정보를 확인할 수 있습니다. 회원 계정이 없는 구조이므로 다른 사람의 기록을 잘못 변경하지 않도록 본인 여부를 확인할 수 있는 범위에서 처리하고, 확인이 어려운 경우 그 사유와 가능한 방법을 안내합니다. 앱 삭제나 기기 데이터 삭제만으로 서버 순위 기록이 삭제되지는 않습니다.
