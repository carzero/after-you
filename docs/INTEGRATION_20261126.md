# AFTER YOU v0.9 · 2026-11-26 자료 통합

사용자 요청에 따라 지금까지 전달된 최신 적용 후보를 게임에 연결했습니다. 무한 스테이지, 추락 시 한 스테이지 복귀, 짧아지는 힌트, 서버 검증 순위 규칙을 유지합니다. 실제 온라인 호스팅 신규 배포 작업은 포함하지 않습니다.

## 배경·타이틀·결과

Ch01_Layers와 Ch02_05_Layers의 개별 레이어를 원본 해시로 확인하고 표시 범위(displayBounds)만 실행용 WebP에 적용했습니다. 컷신 entry와 합성 backdrop은 겹쳐 그리지 않습니다. 이 표시 범위는 발판 판정이나 접점으로 사용하지 않습니다. 발판의 정상·균열·붕괴 이미지는 관찰 상태에 맞춰 표시하며, 미확인 좌우 발판은 같은 이미지를 사용합니다.

4/5챕터는 Clouds v03의 전용 후경/좌우 전경 6종을 사용합니다. 구버전 및 다른 챕터의 구름 재사용은 제거했습니다. 후경 한 장은 두 위치에서 재사용하며 신규 두 장으로 계산하지 않습니다. 왼쪽의 잘린 윤곽은 화면 밖으로 보내고, 중앙 배치·좌우 반전을 하지 않습니다. 구름은 고정 화면 가장자리에 두고 카메라를 중복 적용하지 않습니다. 소품·배경은 장식이며 별도 챕터 완료 규칙을 만들지 않습니다.

UI_Title의 최신 타이틀/로고를 사용하고 기존 SVG 24종은 유지합니다. 작은 화면에서도 출발 버튼을 보이게 압축했습니다. Results_Unlock의 성공/추락/시간 종료/초기 3스테이지 완료·참가자 해금 표현을 실제 게임 상태와 연결했습니다. 문서의 3스테이지 종료 제안은 채택하지 않고 4스테이지 이상 계속 진행합니다. 해금은 실제 저장 상태에 따르고 보상을 반복 지급하지 않습니다. 결과의 기록은 실제 시간과 최고 층수입니다. 온라인 모드에서는 검증 완료 전 계속 진행을 막는 기존 정책을 유지합니다. 오프라인 성공 결과에서 현재 스테이지 재도전도 제공합니다.

## 착지·구조

Landing_Review_v02에서는 새 descent 4장만 추가했습니다. 기존 보정 idle/jump/land와 등록 좌표를 덮어쓰지 않았습니다. 새 포즈는 기존 캐릭터별 화면 배율에 맞추고 제공된 가상 발 기준 초안으로 연결합니다. 점프 300~419ms에 descent를 표시하며 입력 판정은 기존 420ms입니다. 안전 착지 이벤트에만 성공 착지 연출을 사용합니다. 위험 발판은 공중/균열·추락 흐름을 따릅니다. 착지 표시가 다음 입력을 잠그지 않습니다.

Rescue_Transition의 순수 표시 샘플러를 사용합니다. 실패 900~1000ms에 배우별 구름을 표시하고, 1000~1150ms는 캐릭터 렌더링을 직접 숨깁니다. 알파 254의 구름만으로 완전 가림을 보장하지 않습니다. 1050ms 자세/위치 전환을 숨긴 뒤 1150ms부터 구조 자세를 공개합니다. 실제 1400ms 구조·결과 이벤트는 엔진이 담당합니다. 기존 보정 캐릭터 이미지를 유지하며 구름은 배우 컨테이너 안에서 표시합니다. NPC 전환에도 같은 규칙을 적용합니다. 움직임 줄이기는 구름의 과장 이동과 점프 장식을 줄이고 필수 게임 이동·타이밍은 유지합니다.

## 사운드

Audio_Review의 BGM 7곡·효과/반응음 26종, 총 33종을 실행용 MP3로 변환했습니다. 원본 WAV 33개의 SHA256을 검사했으며 출처/변환 내역은 INTEGRATION_PROVENANCE_20261126.json에 기록했습니다. 다운로드 크기와 브라우저 호환성을 위해 음악 80kbps/효과 96kbps MP3를 사용합니다. 원본 WAV/OGG는 사용자가 전달한 원본 ZIP에 보존되며 소스 ZIP에 중복 포함하지 않습니다.

Web Audio의 디코딩된 AudioBuffer로 재생하고, 음악은 실제 원본 길이를 loopEnd로 설정합니다. MP3 디코딩 길이 차이가 있다면 더 짧은 길이로 제한합니다. WAV 원본의 sample-accurate 루프와 동일한 음질/이음새를 확정한 것은 아닙니다. 실제 휴대폰 청음과 루프 자연스러움은 추가 확인 대상입니다.

효과음 최대 4개 + 음악 1개, 플레이어 0.65/NPC 0.2/음악 0.45/마스터 0.5를 적용합니다. 최대 피크 합산 검사와 33 MP3 전체 디코딩 결과는 AUDIO_RUNTIME_CHECKS_20261126.json에 있습니다. 음악은 타이틀과 현재 챕터만 디코딩해 메모리를 줄이고, 배경 변경 시 이전 챕터 버퍼를 해제합니다. 초기 로드는 실패해도 게임을 차단하지 않습니다.

jump/land_safe/tile_crack/fall 등은 게임 이벤트에서 바로 재생합니다. finish는 실제 success/fall/timeout으로 분기하며 기존 소리를 모두 끊고 결과음 하나만 재생합니다. 같은 이벤트 묶음의 rescue는 결과음보다 우선하지 않습니다. 일시정지·설정·탭 숨김·재시도는 소리와 루프를 중단하며 이벤트를 나중에 재생하지 않습니다. 복귀는 기존 수동 재개 정책입니다. 반응음은 녹음 음성이 아닌 합성 모티프이며 한가한 대기 중에만 제한적으로 사용합니다. ending 음악은 자료로 포함하지만 무한 게임에 임의의 엔딩은 만들지 않습니다.
