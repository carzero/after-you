# 현재 버전 v0.5 · 아트 v0.3 적용

오리·토끼 각 7포즈와 도약/착지/구조 VFX를 연결해 주연 4인 모두 제공된 원화로 표시한다. 캐릭터별 고정 배율과 원본 크기를 사용해 오리 land의 비율 왜곡을 방지한다. VFX는 시뮬레이션 시계로 표시하고 일시정지/재시도/움직임 줄이기와 함께 처리한다. PNG 43개 SHA-256 확인, 실행용은 콘셉트/box_revision을 제외한 40개 WebP.

검증: 단위/API 17개, 브라우저 10개 항목(오리·토끼 320px 포즈/VFX 2개 추가), 온라인 공유 순위 1개를 확인. 원화 식별 속성과 선택 버튼 속성을 분리한 뒤 관련 3개 항목을 재실행했다. 실제 기기 검증은 미실행.

무한 진행·이전 단계 복귀·짧아지는 힌트·온라인 스코어보드 로직은 v0.4 그대로다. 온라인 공개 호스팅 배포는 여전히 미실행. 실제 음원·연속 모션 프레임·최종 가장자리 정리는 미완료. 아래는 이전 버전의 이력이며 최신 아트는 ART_MANIFEST.md/ART_REGISTRATION.json을 참고한다.

# 현재 버전 v0.4 · 무한 진행과 온라인 기록

사용자 변경 요청 반영: 성공 시 계속 상승, 추락 시 한 단계 하락(첫 단계 유지), 힌트 2.6초부터 0.2초씩 감소해 최소 0.6초. 최고 안전 도달 층수를 점수로 사용해 재등반 중복 가산을 막는다. 기존 3스테이지 제한을 제거했으며 후속 단계는 같은 초안 아트를 사용한다. 시간 종료는 같은 단계 재시작.

온라인 API와 영구 순위 저장을 구현했고 독립 브라우저의 기록 공유를 검증했다. 서버는 재생 기록으로 점수를 계산하며 다운로드 HTML은 연습용으로 구분한다. 현재 공개 URL/외부 배포는 없음. 호스팅과 영구 디스크/HTTPS 연결이 필요하다. 상세 규약은 ONLINE.md. 아래 v0.3 기록은 이전 검증 이력이다.

검증: 단위/API 16개 통과. 기존 브라우저 회귀 7개와 신규 이전 단계 복귀 검사 1개 통과. 별도 온라인 브라우저 검사 1개에서 두 사용자 공유 순위/응답 유실 재전송/단계 하락 검증. 새 단일 HTML의 오프라인 상승·하락·재시작과 배포 ZIP의 Node 실행/정적 파일/초기 빈 순위도 확인. 공개 배포는 미실행.

# 먼저 가세요 · 플레이 개선 v0.3 (아트 초안 v0.2)

2026-11-18 · 기존 아트 v0.2로 반복 플레이·모바일 배치·움직임 설정 개선. 환경 초안 수정·재게시·배포·Git push는 수행하지 않음.

## 완료

- Vite + 브라우저 기본 JavaScript. 서버/API/계정 없이 정적 배포 가능한 구조.
- 8/10/12줄, 35/38/42초. 시작 전 2.6/2.2/1.8초 전체 안전 경로와 앞쪽 발판 미리보기. 경로는 라운드 생성 시 비공개 필드에 고정.
- 좌우 버튼/방향키, 420ms 이동 중 중복 입력 잠금, 이동을 따라가는 카메라, 작은 화면에서 다음 발판과 입력 유지.
- 플레이어 1명 + NPC 3명. NPC 판단 함수에는 관찰 배열/현재 줄/도전 성향만 전달. 비밀 경로를 전달하지 않음. 안전 관찰을 따라가거나, 무너진 반대편을 추론하거나, 성격별로 머뭇거리며 무작위 도전.
- 공개 안전/붕괴 상태 유지. 물리 충돌 없음. 같은 발판 동시 착지 허용, 각 착지 개별 판정.
- 균열 → 공중 유지 → 추락 → 구름 회수/반송 결과 → 한 번 터치 재시도. 매번 새 Game 인스턴스로 경로/배우/이벤트 초기화.
- 일시정지, 설정, 탭 숨김 시 시뮬레이션 중단 및 모든 재생음 중단. 탭 복귀 후 사용자가 재개할 때까지 정지. 경과한 백그라운드 시간은 제한시간에서 차감하지 않음.
- 스테이지 해금·최고 기록·1챕터 완료 후 네 캐릭터 해금. localStorage 버전 1. 손상/알 수 없는 버전은 기본값 복원. 잘못된 개별 필드는 정규화. 저장 접근 실패 시 메모리에서 계속하며 저장 불가 안내.
- 음악/효과음/진동/움직임 줄이기 저장. 진동 기본 꺼짐. 아트 초안/일부 임시 아트/합성음을 화면에 명시. 아트/오디오 규약 별도 문서화.

## 판정 정책

- 타이머는 힌트 종료 후부터 진행. 이동 중에도 감소.
- 제한시간과 착지가 같은 시점이면 **시간 종료 우선**. 성공 직전 이동도 완료되지 않으면 실패. finish 이벤트는 한 번만 발생.
- 플레이어의 위험 착지 확정 후에는 이미 실패한 라운드이므로 타이머를 멈추고 1400ms 회수 연출 진행. 뒤늦은 시간 종료로 실패 사유를 덮지 않음.
- NPC/플레이어가 같은 시점에 이동해도 안전 경로는 바뀌지 않음. 관찰은 착지 확정 시에만 공개. NPC는 그 이후 결정에서 사용할 수 있음.
- 일시정지는 힌트/이동/추락/타이머/NPC를 함께 중단. 설정 창에서도 동일.
- 네 캐릭터의 플레이 성능 동일. NPC 성향은 현재 참가 순서의 소심/허세/도전형 슬롯으로 분리.

## 실행

저장소 `/workspace/after-you`에서 `npm ci --cache /workspace/.npm-cache`, `npm run dev`. 이미 설치된 환경에서는 `npm run dev`만 실행. `npm test`, `npm run test:browser`, `npm run build`로 확인. 기본 Chromium 경로는 `/usr/bin/chromium`, 다른 경로는 `CHROMIUM_PATH`로 지정. 배포하거나 환경을 게시하지 않고 로컬 구현만 수행.

## 아트 v0.2 구현 메모

게임 규칙/NPC 로직(`src/game.js`)은 변경하지 않았다. `poseFor()`가 시뮬레이션 시간에서 포즈만 선택하며, 착지 키 포즈는 입력 잠금 시간을 늘리지 않는다. 출발은 모든 실행용 이미지 로드 후 시작하고, 재시도 시 렌더러 착지 기록과 회수 레이어를 초기화한다. 이미지 불러오기 오류는 출발 전에 안내한다. 구조음이 결과 초기화에 끊기는 문제는 이벤트 소비 전 정리 + 140ms 결과음 예약으로 수정. 화면 캡처는 로컬 `test-results/art-*.png`에 생성(테스트 출력이므로 Git 제외).

## 플레이 개선 v0.3

- `Game.skipRescue()`는 위험 착지로 이미 실패한 라운드만 종료한다. 시간/경로/보상을 바꾸지 않고 rescue(skipped=true)/finish를 한 번씩 발생시킨다. UI는 같은 방문에서 두 번째 추락부터 표시. 원래 연출의 finish와 중복되지 않음.
- OS `prefers-reduced-motion` 또는 저장 옵션 중 하나라도 활성화되면 실제 점프 아크와 회전 모두 감소. OS 설정의 실행 중 변경도 반영. 설정 저장 형식은 변경하지 않음.
- 568×320/844×390 가로 화면은 2열 배치, 세로 화면은 기존 배치. 이동 버튼 최소 높이 44px. 320×568, 375×667, 390×844 포함 회귀 검증.
- 랜덤 경로 자동 비교 결과만으로 제한시간/힌트/NPC 수치는 변경하지 않음. 현재 사람의 약 30초 플레이·재미 검증과 새 원화/음원은 여전히 필요.
