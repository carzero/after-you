# AFTER YOU 타이틀 구성 시안 v02

기존 타이틀의 흔한 분위기를 개선하기 위한 세 가지 독립 시안. 실제 게임과 배포 설정은 변경하지 않았습니다. 기존 WebP 원화를 HTML/CSS로 배치했습니다.

- A 양보하는 척 (추천): 두 캐릭터가 서로 먼저 가라고 미루는 코미디. 대사와 큰 붉은 제목으로 게임의 성격을 전달.
- B 소원 접수처: 타이틀을 세계관 속 신청서로 구성. 접수와 마감에 관한 문구로 제한 시간을 표현.
- C 딱 한 발: 한 캐릭터와 건너편 발판을 배치해 첫발의 긴장감에 집중.

`node tools/title-concepts/build.mjs`로 외부 의존성 없는 HTML을 생성합니다.
`node tools/title-concepts/check.mjs`로 오프라인 이미지 로딩, 세 안의 참가자 선택과 복귀, 320px 화면 버튼 영역과 가로 넘침, JS 오류를 확인했습니다. Chromium이 필요합니다.

ZIP의 TITLE_REVIEW.html을 브라우저에서 열면 됩니다. 버튼은 시안 탐색만 제공하며 게임 실행, 실제 순위 및 저장 기능은 연결하지 않았습니다. 캐릭터 선택에 표시된 네 명은 화면 확인용이며 실제 해금 규칙을 변경하지 않습니다.
