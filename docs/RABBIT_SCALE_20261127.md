# v0.10.1 · 근육 토끼 동작별 크기 보정

등록된 기본 포즈는 idleRegistration의 .112 배율을 사용하지만, 추가 연기 원화는 기존 공통 .104 배율로 표시되고 있었습니다. 특히 가로형 안도 원화는 머리와 가슴이 작게 그려져 같은 배율을 적용하면 착지 후 눈에 띄게 작아졌습니다.

원화 파일을 수정하지 않고 `src/rabbit-registration.js`에서 토끼의 연기 포즈별 배율과 접지점을 별도로 등록했습니다. 양보 .112, 살펴보기 .104 및 발 기준 1490, 안도 .131을 사용합니다. 착지 직전 포즈는 대기 기본 배율의 1.06배로 맞췄습니다. 귀·손의 확장과 웅크림을 포함한 전체 외곽 크기로 정규화하지 않고, 머리와 가슴 크기를 수동 비교했습니다. 자세에 따른 자연스러운 높이 차이는 유지합니다.

실제 플레이의 대기 → 점프 → 착지 직전 → 착지 → 안도 → 살펴보기와 추락 전환을 캡처했습니다. 원본에서 수동 확인한 머리 폭을 실제 렌더링 배율에 적용해 대기 대비 ±10% 범위를 확인하는 브라우저 회귀 검사를 추가했습니다. 다른 캐릭터와 기본 등록 포즈의 배율은 그대로입니다.

게임 판정, 아이템, 점수와 서버 기록 형식은 변경하지 않았습니다. 배포 ZIP을 압축 해제한 후 기존 인증된 PC에서 UPDATE.cmd로 배포할 수 있습니다. 이 환경에서 서비스에 직접 배포하지 않았습니다.
