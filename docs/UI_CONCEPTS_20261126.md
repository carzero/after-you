# 몰입형 UI 시안 3종 · 2026-11-26

사용자가 게임 영역을 크게 쓰는 UI 시안을 요청했습니다. 실제 게임 엔진과 배포 UI는 수정하지 않고 기존 아트를 사용한 독립 비교 화면을 만들었습니다.

- A 하늘 우체국: 기존 따뜻한 색과 브랜드를 이어가며, 큰 헤더를 없애고 점수·시간을 화면 모서리에 배치합니다. 현재 추천안입니다.
- B 클라우드 러시: 큰 높이 기록과 대비가 높은 조작 버튼으로 반복 도전/기록 경쟁을 강조합니다.
- C 구름 동화극장: 중앙의 작은 점수와 둥근 조작 버튼, 절제된 정보를 사용해 풍경과 캐릭터에 집중합니다.

각 시안은 타이틀/플레이/결과를 제공합니다. 전환 버튼과 캐릭터 선택, 예시 점수 이동, 일시정지를 조작할 수 있습니다. 실제 게임의 판정·순위·저장·사운드가 연결된 것이 아니며 모든 숫자는 시안용 예시입니다. 캐릭터/배경 원본을 다시 그리지 않고 현재 런타임 WebP를 사용했습니다.

사용: ZIP의 압축을 풀고 UI_REVIEW.html을 브라우저에서 엽니다. 외부 서버·인터넷·폰트 없이 동작합니다. 게임 화면을 바꾸는 배포 파일이 아닙니다.

재생성:

```
node tools/ui-concepts/build.mjs
node tools/ui-concepts/check.mjs
```

검증: 오프라인 PNG/WebP 로딩, 세 화면 전환, 모의 이동·일시정지·캐릭터 선택, 320×568에서 시안별 세 화면의 조작 영역 44px 이상 및 컨테이너 내부 배치, 페이지 가로 넘침 없음, pageerror 없음. PC 비교 화면과 320px 개별 캡처를 함께 제공합니다. 원본 게임 기능 회귀 검사는 게임 코드가 바뀌지 않아 반복하지 않았습니다.
