# v0.10.0 · 아이템

6번째 안전 발판에 NPC보다 먼저 도착하면 아이템을 받습니다. 동시 도착은 보상하지 않습니다. 같은 도전에서 한 번 도달한 구간과 그 아래 구간은 재보상하지 않습니다. 보관함이 가득 차면 보상을 건너뜁니다.

- 기억 쪽지 (25%): 아직 지나지 않은 안전 경로를 1초 동안 표시.
- 눈치 안경 (75%): 다음 안전 발판 하나를 1초 동안 표시.
- 보관은 최대 3개이며 구간 이동과 추락 후에도 유지합니다.
- 새 도전, 타이틀 복귀 후 새 출발, 페이지 새로고침에서는 초기화합니다.
- 플레이어가 발판 위에 멈췄을 때 보관함을 눌러 사용합니다. 사용 중 캐릭터와 NPC 이동은 멈추지만 제한 시간은 흐릅니다. 일시정지·설정에서는 효과 시간과 제한 시간 모두 멈춥니다.

공유 Game 시뮬레이션이 보상과 소비를 결정합니다. 서버는 보유 상태를 도전 기록에 저장하고, 이동·아이템 입력을 같은 시간 순서로 재현합니다. 클라이언트가 주장하는 아이템 수량은 사용하지 않습니다. 기존 Durable Object 바인딩과 순위 기록을 유지합니다.

원화는 imagegen으로 제작한 투명 PNG `assets/source/items/items-atlas.png`입니다. 배포용 WebP는 `assets/runtime/items/atlas.webp`이며, 두 아이콘을 아틀라스의 좌우 영역으로 표시합니다. 글자는 HTML로 표시합니다.

배포는 기존 인증된 PC에서 업데이트 ZIP의 UPDATE.cmd로 진행합니다. 이 환경에는 Cloudflare 로그인 정보가 없습니다.

검증: 41개 단위/API 테스트, 아이템 획득·소모·추락 후 보관·새 도전 초기화 모바일 브라우저 테스트, 실제 로컬 Cloudflare Workers에서 아이템 사용을 포함한 두 브라우저의 순위 등록과 전송 재시도를 확인했습니다. 인터넷 연결 없는 실행 HTML의 시작·이동도 확인했습니다.
