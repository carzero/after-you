기기 데이터는 관계 관리 기능 또는 사이트 데이터 삭제로 제거할 수 있습니다. 서버 데이터나 문의 내용에 관한 삭제·처리 정지 요청은 위 연락처로 접수합니다. 식별에 필요한 최소한의 확인을 거쳐 처리하며, 이미 삭제되어 보유하지 않는 정보는 복구하거나 제공할 수 없습니다.
